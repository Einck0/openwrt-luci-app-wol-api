# Project experience

## Presence is network evidence, not power telemetry
The previous LuCI logic labelled STALE/DELAY/PROBE/PERMANENT neighbors Online and missing entries Offline. Stale neighbors survive an offline device and therefore cannot prove current liveness. IPv4 hints/cache now only select candidates; a bounded iputils-arping probe checks fresh reply MAC against configured identity. No response means Unreachable, operational or identity error Unknown. Standby NICs/ARP proxies can reply; this does not prove Windows is awake. Probes never call etherwake.

## OpenWrt SDK and single-package feed
This is a single-package repository with its Makefile at root. Official SDK feed scanning uses -mindepth 1 and skips a feed-root Makefile. CI stages Makefile/root/htdocs inside a luci-app-wol-api child of a temporary feed, sets FEED_DIR explicitly, and uses the stable x86_64-openwrt-24.10 SDK for architecture-all IPK. Snapshot may emit APK and must not be substituted. OpenWrt 24.10 control Version is PKG_VERSION-rPKG_RELEASE; dynamically validate it, not a hardcoded -1 value. IPK from scripts/ipkg-build is outer tar-gzip, not assumed Debian ar. Release runs in a separate artifact-only job and requires GH_REPO because there is no checkout/git context.

## Validation and safety
`node --test tests/*.test.js` exercises isolated probe, LuCI click path and actual workflow IPK extraction with generated fixture archives. Optional WOL_API_REAL_ARPING supplies an external iputils binary; that test is a runtime smoke only, not evidence of a positive physical PC state. Target runtime ucode is on the router, not installed locally. Probe helper executable is assured by Makefile INSTALL_BIN. Hostile JSON characters, glob expansion, tool errors and click-time unsaved form inputs have explicit regressions.

Keep main; do not create build/release branches. Normal version tags allowed. Public repo excludes all runtime config/credentials, private scratch and .pi session/memory artifacts. Router installation is separately authorized per task, never built into CI. Preserve UCI conffiles, obtain private rollback backup and compare configuration fingerprints without outputting values. Do not perform real WOL/power actions as tests.
